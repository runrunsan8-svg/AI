# NNビル 書類確認・無料ブラウザー版

PCのChrome/Edgeから使える、インストール・APIキー・サーバー処理不要のアプリです。

公開先: https://runrunsan8-svg.github.io/AI/nn-free/

## 数量・単価・小計・合計を確認する

1. PDF/JPEG/PNGを添付します。写真は貼り付け枠をクリックしてCtrl+V（Macは⌘V）でも添付できます。1ファイル12MBまで、PDFは5ページまでです。
2. **無料で数字を読み取る**を押します。初回はブラウザーがOCRプログラムを読み込むため時間がかかります。文字を選択できるPDFはテキストを取り出し、画像やスキャンPDFは無料OCRで読み取ります。いずれもPC内で処理します。
3. 入力された候補を原本と照合します。列は「数量→単価→各行の小計」の並びと仮定しています。違う数字や列の並びは修正し、抜けた行は追加してください。区切りが曖昧な数字、読めなかった消費税・合計は空欄になります。税がない書類は消費税0・税率0を入力してください。税率は10%の仮設定です。
4. **入力した数字を検算・比較する**を押します。次を別々に表示します。
   - 数量×単価と、各行の記載小計との差
   - 数量×単価の合算と、書類の税抜小計との差
   - 各行の記載小計の足し算と、書類の税抜小計との差
   - 各行の記載小計の合算＋記載消費税と、記載合計との差
   - 数量×単価と単一税率から検算した、消費税・合計との差
5. 全数値と品目の漏れを原本で確認してから「要確認」を外し、「全数値と品目の漏れを原本と照合した」をチェックします。未確認のままでも検算できますが、確認完了・支払済みには進めません。

「読み取った文字を確認・修正する」からOCR文を直して、候補を作り直すこともできます。表の罫線、桁区切り、傾き、数字の密集、合計が複数ある書類では誤読や抜けが起こります。読み取り候補は正解を保証しません。「10,000」が「10,.000」や「2,000」が「2.000」になった場合は、推測で金額を決めず空欄にして原本照合を促します。中止ボタンは現在のページの処理完了後に読み取りを中止します。

## その他の機能

「サンプルで試す」→「検算・比較する」で、明細2,000円・合計2,200円の差を確認できます。サンプル後に実書類を添付するとサンプル値を消去します。

見積書・契約書を保存すると比較先として選べます。品目名の完全一致で数量・単価・小計を比べます。同名行が複数ある場合は手動照合を促します。金額相違のメールは下書きとコピーだけです。送信・支払いは自動実行しません。

## 保存と扱える書類

- 添付・OCR文・入力値を外部へ送信しません。OCR、言語データ、PDFプログラムは同じサイトから取得します。サイト提供者には通常のページアクセス記録が残る場合があります。
- 保存ボタンで添付と入力情報を同じPC・同じブラウザー内（IndexedDB）に保存します。OCR原文は保存せず、候補を反映した入力欄と添付原本を保存します。再保存は新規書類の追加です。
- サイトデータの削除やPC・ブラウザーの変更で保存内容が使えなくなります。原本は別途保管してください。共有PCでの利用は避けてください。アプリ内の暗号化やログインはありません。
- 明細100行まで。数値は整数10桁・小数4桁まで、検算は整数演算で行います。各行を円単位で四捨五入後、単一税率で消費税を四捨五入します。混合税率、負数の値引き、源泉徴収、異なる端数処理には未対応です。
- 縦書きや、数量・単価・小計の列順が異なる書類では手入力で修正してください。読めない値を0円で補いません。

## 開発・公開

リポジトリ直下で `python3 -m http.server 3000 --bind 127.0.0.1` を実行し、`/nn-free/` を開きます。Node/Pythonのパッケージインストールは不要です。`main` に反映すると、既存のGitHub Pages設定で公開されます。利用者の書類やAPIキーはGitHubに追加しないでください。

パーサーの回帰テスト（開発時のみNodeを使用）:

```sh
node --test nn-free/tests/parser.test.cjs
```

同梱プログラムとライセンスは [THIRD_PARTY.md](THIRD_PARTY.md) を参照してください。
