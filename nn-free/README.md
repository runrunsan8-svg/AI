# NNビル 書類確認・無料ブラウザー版

サーバー処理・APIキー・インストール不要の静的アプリです。既存のGitHub Pagesの公開対象にこのフォルダーを含めると、サイトの `nn-free/` から使えます。現在の作業ファイルを作成しただけでは公開されません。リポジトリへの反映とPages公開が必要です。

## 使い方

1. 公開されたページをPCのChromeまたはEdgeで開きます。
2. 「サンプルで試す」→「検算・比較する」で差額2,200円とメール下書きを確認できます。
3. 実際の書類はPDF/JPEG/PNGを選択します。写真は貼り付け枠をクリックしてCtrl+V（Macは⌘V）でも添付できます。1書類につき1ファイル、12MBまでです。
4. プレビューを見ながら品目・数量・単価・記載金額・消費税・合計を手入力します。自動OCR・AI読取はありません。PDFプレビューが無効なブラウザーでは表示設定を確認してください。
5. 原本照合後に各「要確認」を外して「全数値と品目の漏れを原本と照合した」をチェックします。
6. 検算・比較し、下書きをコピーしてメールアプリで送信します。送信・支払いは自動実行しません。
7. 保存すると添付と入力情報が同じPCの同じブラウザー内（IndexedDB）に残ります。保存済み書類を比較先に選べます。状態を切り替えたり、読み込み・削除できます。変更後の再保存は新規書類として追加します。

## 保存と計算

- 書類と入力値の外部送信はありません。コードに外部通信はなく、CSPで接続を禁止しています。サイト提供者には通常のページアクセス記録が残る場合があります。
- サイトデータ消去・PCの変更・ブラウザー変更で保存内容は利用できなくなります。原本は別途保管してください。共有PCでの利用は避けてください。アプリ内の暗号化やログインはありません。
- 検算は整数演算で小数4桁まで扱い、各行の円単位四捨五入後、単一税率で消費税を四捨五入します。負数の値引き、混合税率、源泉徴収、異なる端数処理には未対応です。
- 比較は品目名の完全一致で行います。同名の品目が複数ある場合は手動照合を促します。
- 添付が変わると原本照合状態を解除します。数字の抜け・品目の漏れは必ず目視確認してください。

## 開発時確認

リポジトリ直下から `python3 -m http.server 3000 --bind 127.0.0.1` で配信し、`/nn-free/` を開きます。利用者によるインストールは公開後には不要です。
